# MoM 남은 작업

현재 구현 기능과 사용법은 [프로젝트 README](../README.md), 검사·배포 이력은 [문서 안내](README.md#검증과-배포-기록)에 있습니다. 이 목록은 미해결 문제와 추가 결정만 다룹니다. 기능이 배포됐다는 사실과 실제 제공사·장비·음성 품질이 검증됐다는 사실을 구분합니다.

## 조사와 검증

| ID | 남은 범위 | 다음 행동 / 완료 기준 |
| --- | --- | --- |
| M01 Samsung Internet 붙여넣기 | Galaxy Tab 외장 키보드의 붙여넣기 실패 원인 미확정 | 사용자는 Paste·Ctrl+V 실패와 일반 타이핑 성공을 보고했고 Chrome으로 전환했습니다. 재조사 시 Samsung 버전과 비밀값 없는 실제 입력·포커스·잠금 이벤트부터 확인합니다. 합성 이벤트 통과를 실제 브라우저 해결로 보지 않습니다. |
| M05 실제 마이크·장비 | 장비·브라우저·권한 상태별 검증 | Galaxy Tab 마이크 작동 사용자 보고가 있지만 브라우저가 명시되지 않았습니다. 녹음·저장·재열기·재생과 백그라운드 중단을 실제 장비에서 구분해 확인합니다. 에이전트가 사용자 마이크나 오디오를 임의로 사용하지 않습니다. |
| M06 실제 STT → 정리 품질 | 재현 가능한 인증 호출과 결과 평가 | 사용자가 앱 UI에 제한된 시험 키를 입력하고 공개 가능한 시험 음성의 전송을 승인합니다. KR/EN/ID, 이름·숫자·부정어, 겹침·누락·나중 발언의 정정, 선택 전사, 암호화 재열기, 정리·편집·내보내기를 확인합니다. 사용자 성공 보고와 합성 응답 검사를 구분하고 실제 사용량·비용·라우팅·보관 정책을 확인합니다. |
| M09 기존 검사 부채 | 오래된 모델·동의·권한 fixture와 현재 흐름의 불일치 조사 | [준비 처리 기록](superpowers/evidence/2026-10-18-preparation-progress/README.md)의 기존 실패와 [겹침 처리 기록](superpowers/evidence/2026-10-19-overlap-minutes/README.md)의 baseline 재현을 출발점으로 삼습니다. [정책 복구 검사](superpowers/evidence/2026-10-19-stt-policy-recovery/README.md)의 기존 전사/정리 검사 실패 2개도 함께 추적합니다. 해당 기록의 실패 수를 현재 전체 저장소 실패 수로 일반화하지 않습니다. 실제 회귀와 낡은 기대값을 구분하고 보안·동의 검사를 완화하지 않습니다. |

API 키 확인 성공은 실제 모델 실행을 검증하지 않습니다. 계정의 ZDR 정책에 맞는 엔드포인트가 없거나 네트워크가 끊기면 결과가 없을 수 있으며, 재시도는 추가 비용을 만들 수 있습니다. 저장된 비밀값을 읽거나 임의로 유료 호출해 검증하지 않습니다.

## 설계·결정이 필요한 기능

| ID | 남은 범위 | 현재 구현과의 경계 |
| --- | --- | --- |
| M02 회사·도메인 문맥 / 용어집 | 재사용 용어집과 정리용 회사 문맥 | 메모별 STT 용어·맥락은 암호화 저장하고 지원 모델의 실제 매개변수로 보냅니다. 계정별 실제 지원과 정확도 개선은 검증이 필요합니다. 재사용 저장 범위·적용 방식은 별도 설계합니다. |
| M03 재사용 프롬프트 관리 | 작성 지침 저장·선택·편집·삭제 | 현재 섹션 프리셋과 메모별 추가 지침은 프롬프트 라이브러리가 아닙니다. 버전, 적용/취소, 기본 근거 규칙의 유지부터 결정합니다. |
| M07 소스 공개 범위 | 공개할 메타데이터·레퍼런스·Git 이력 검토 | [MoM 라이선스 1.0](../LICENSE)과 앱 안내는 적용됐습니다. 저장소 공개 설정과 자료 공개 범위는 별도 결정입니다. [채택 기록](16-mom-source-available-license-draft.md)을 보존하며, 과거 공개 준비 감사가 이후 변경까지 검토한 것으로 보지 않습니다. |
| M08 암호·PIN·기기 보호 | 복구·기기 보호 설계와 잔여 위험 | 신규 보관함 15자 이상, 기존 암호 호환, 인증 실패 3회 경고·5회 삭제는 구현됐습니다. 짧은 PIN, 기기 보호 키와 암호 복구는 미구현이며 별도 보안 설계가 필요합니다. 초기화는 삭제이지 복구가 아닙니다. 손상된 암호화 헤더도 인증 실패로 집계될 수 있고 복사된 DB에는 횟수 제한이 적용되지 않습니다. [보안 감사](superpowers/evidence/2026-10-29-security-release/security-audit.md)의 검증 범위와 한계를 확인합니다. 실제 계정·브라우저·OS 보안 설정은 임의로 바꾸지 않습니다. |

전체 암호화 보관함 백업·복원과 기기 이전, 중단된 녹음의 안전한 복구, 입력 한도를 넘는 긴 전사의 계층형 정리는 아직 구현하지 않았습니다. 각각 형식·복구·버전·실패 처리와 검증 범위를 정한 뒤 착수합니다. 선택적 음량 정규화도 후속 제안이며, 노이즈 제거는 현재 범위에서 제외합니다.

M04(OpenRouter STT·동적 제공자)는 구현된 항목입니다. [설계](superpowers/specs/2026-10-03-openrouter-stt-design.md)와 [계획](superpowers/plans/2026-10-03-openrouter-stt.md)은 이력으로 보존하고, 실제 제공사 검증은 M06에서 추적합니다. 파형·저장 음성 미리듣기 역시 구현돼 별도 미구현 과제로 두지 않습니다.

## 작업 기준

새 기능은 사용자 결정과 관련 설계 범위 안에서 진행합니다. 이 TODO가 추가 구현이나 실제 자격 증명 사용을 승인하지는 않습니다. 검사는 [변경 영향 기준](prompts/change-impact-test-agent.md)으로 고르며 관련 저장 실패·잠금·데이터 손실 검증을 유지합니다. 같은 코드·빌드·환경의 통과 근거는 재사용하고, 전체 스위트는 명시적 요청이 있을 때 실행합니다.
