# 디자인 샘플용 화면과 기능 목록

[문서 인덱스](README.md) · [요구사항](01-product-requirements.md) · 기록 기준일 2026-09-30

이 문서는 디자인 샘플을 위한 **제안 PROPOSALS**다. 여섯 화면에 제시한 모든 기능이 확정된 MVP 범위라는 뜻은 아니다. 확정된 사용자 요구를 표현하는 부분과 편의 기능 후보를 구분하고, 실제 구현 전에 [미결정 목록](09-decisions-and-roadmap.md)으로 범위를 선택한다.

## 핵심 흐름

```mermaid
flowchart LR
    K[잠금 해제] --> I[가져오기]
    I --> P[준비와 전사 진행]
    P --> T[전사 검토]
    T --> M[회의록 생성과 편집]
    M --> E[Markdown 내보내기]
```

핵심 단계는 가져오기 → 전사 검토 → 회의록이다. 청크 고급 설정과 모델 비교는 보조 영역으로 둔다. 프로젝트 목록·제공자 설정을 별도 화면으로 설계해도 사용자가 모든 화면을 순서대로 방문할 필요는 없다. 기술 파라미터보다 작업 상태와 다음 행동을 우선한다.

## 화면 1 로컬 프로젝트 홈

**화면 제안:** 잠금 해제 후 제목, 날짜, 녹음 길이와 상태가 있는 프로젝트 목록을 보여준다. 새 회의 가져오기, 이어서 처리하기, 이름 변경과 삭제, 로컬 저장 안내·사용 공간 표시가 후보 기능이다. 프로젝트 목록 관리의 첫 버전 범위는 결정 전이다.

빈 상태에는 파일 가져오기 행동과 보관·전송 안내를 둔다. 미완료 프로젝트에는 마지막 완료 단계와 필요한 원본 재선택 여부를 보여준다. 삭제는 무엇이 로컬에서 지워지고 원본·내보낸 파일·외부 제공자 자료에는 어떤 영향이 없는지 구분한다. 잠금 상태에서는 암호화된 제목과 상세 목록을 보여주지 않는다.

## 화면 2 파일 가져오기

파일 선택과 drag and drop, 형식·길이·바이트·오디오 트랙 표시, 가능한 경우 재생, 회의 제목과 여러 예상 입력 언어가 후보다. 실제 지원 여부 확인 후 해당 조합만 처리 가능으로 표시한다. 파일 선택 중 상태, 검사 오류, 오디오 없음과 지원하지 않는 포맷을 구분한다.

청크 설정은 10분·15분, 겹침은 10초·15초로 단위를 명시한 고급 영역을 제안한다. 자동 압축은 필요한 경우의 후보 정책이며 최종 인코딩 크기와 품질 조건을 설명한다. 지원 범위가 정해지기 전 모든 포맷·완벽한 변환을 약속하지 않는다.

외부 STT 제공자, 보낼 오디오 범위, 키 필요 여부와 비용 발생 가능성을 실행 전에 보여준다. 선택할 수 있는 입력 언어와 출력 회의록 언어가 다르다는 것을 자연스럽게 표현한다. 녹음이 여러 언어를 포함한다는 선택을 제외 언어 삭제 옵션처럼 보이게 하지 않는다.

## 화면 3 준비와 STT 진행

오디오 추출, 분할, 압축·검사, STT 요청, 결과 저장을 단계로 표현하는 안이다. 청크별 원본 시간 구간, 실제 크기, 상태, 재생 가능 여부와 실패 이유를 보여준다. 전송 완료와 로컬 저장 완료를 구분한다.

실패 청크만 재시도, 취소, 완료분 보존과 재개는 후보 기능이다. 취소해도 이미 실행된 외부 요청 비용을 취소한다고 표시하지 않는다. 진행률이 아직 측정되지 않는 단계에는 거짓 백분율·남은 시간을 만들지 않는다. 일부 실패는 전체 성공과 구분하고, 완료한 구간은 검토할 수 있게 하는 안이다.

잠금 버튼은 모든 작업 화면에서 찾을 수 있어야 한다. 진행 중 잠금 시 보관·정지 정책은 보안 설계의 미결정 사항이다. 정책이 정해지기 전 잠그고 백그라운드에서 계속 처리된다고 약속하지 않는다.

## 화면 4 전사 검토

시간순 전사와 원본 오디오 탐색, 원시 청크·합친 전사의 전환 또는 대조, 불확실한 경계 표시, 검색과 전사 편집을 제안한다. 청크별 원시 출력은 사람이 편집하는 전사 버전과 구분한다.

시간·화자 표시와 클릭 탐색은 모델의 실제 능력에 따라 제공한다. 단어 시간이 없으면 구간 수준, 화자가 없으면 미제공 상태로 표현한다. 청크의 화자 A가 전역의 같은 사람이라고 자동 표시하지 않는다. 경계의 대안 텍스트를 비교·선택할 수 있는 UI는 후보이며 완벽한 중복 제거는 약속하지 않는다.

누락 청크, 미확정 경계와 사용자 수정이 있는 상태를 보여준다. 부분 전사로 회의록을 만들게 허용할지 결정 전이며, 허용하더라도 전체 회의 결과로 표시해서는 안 된다.

## 화면 5 회의록 생성과 편집

출력 언어 선택, 회의록 항목 선택, 편집 가능한 결과와 Markdown 내보내기는 확정 요구를 표현한다. 모델 선택, 항목 순서, 프리셋, 추가 지시와 재생성은 제안 상세다. 항목 후보는 요약·주제·결정·담당자와 기한을 포함한 할 일·미결정 질문·원문 시간 근거다.

요약과 할 일, 표준, 상세 프리셋을 후보로 제공한다. 선택하지 않은 항목은 결과에도 넣지 않는 방향이다. 출력 언어를 한국어로 고정하지 않는다. 담당자·기한이 없으면 미정으로 표시하고 정보를 만들어내지 않는다.

생성 전 사용한 전사 버전과 외부 전송을 표시한다. 생성 중, 실패, 편집 후 새 전사 버전 등장, 저장 완료, 내보내기 실패 상태가 필요하다. 재생성은 편집본을 보존하는 안이며 출력 설정 변경 시 저장된 STT를 활용한다. 임의 Markdown 템플릿 붙여넣기는 답이 확정되지 않아 첫 버전의 기본 기능으로 넣지 않는다.

## 화면 6 제공자 설정과 비교

OpenAI·OpenRouter 키 입력, 마스킹, 지우기, 보관 정책과 연결 상태가 후보다. 앱의 잠금 비밀값과 API 키를 별도로 설명한다. 인증 오류가 읽혔다는 이유로 연결 완료·추론 가능이라고 표시하지 않는다. Cloudflare Workers AI는 현재 보류 안을 보여줄 수 있으나 설정이 존재한다고 지원 완료로 표시하지 않는다.

모델 비교는 고급 영역으로 둔다. 같은 오디오 청크의 STT 비교와 같은 선택 전사문의 회의록 비교를 분리한다. 입력 버전, 모델·설정, 실행 시간과 제공된 사용량·비용을 표시하고 실측·추정·미제공을 구분한다. 추가 호출 전 범위와 비용 가능성을 드러낸다.

## 공통 잠금 화면

잠금 최초 설정, 잠김, 해제 중, 잘못된 비밀값, 손상된 저장소·복구 필요와 해제 완료를 설계한다. 화면 blur·모달 표현과 실제 민감 DOM 제거·저장 암호화는 함께 필요하다. 제목·검색 결과·오디오 재생 정보를 가린 일반 잠금 화면을 제안한다.

강한 암호문을 권장하고 짧은 PIN의 오프라인 공격 한계를 설명한다. 복구 키와 암호화 백업은 제안 상태다. 분실 시 기존 데이터 복호화가 불가능할 수 있다는 설명을 첫 설정에 포함하는 안이다. 자동 잠금 시간·멀티탭·진행 중 잠금·API 키 제거 시점은 아직 선택하지 않았다.

## 상태 표현 목록

| 상태 | 사용자가 알아야 할 것 | 주요 행동 후보 |
| --- | --- | --- |
| 빈 상태 | 시작 방법과 로컬 보관·외부 전송 구분 | 파일 가져오기 |
| 검사·준비 중 | 현재 단계와 아직 전송되지 않은 범위 | 취소·잠금 |
| STT 중 | 청크별 완료·실패·저장 상태 | 취소·완료분 검토 |
| 부분 실패 | 빠진 구간과 재시도 비용 가능성 | 실패분 재시도 |
| 전사 검토 필요 | 경계·화자·누락의 불확실성 | 오디오 확인·수정 |
| 생성 중 | 선택 전사·출력 설정 | 중단·기존 결과 보기 |
| 완료 | 검토된 범위와 저장 여부 | 편집·.md 내보내기 |
| 저장 실패 | 완료 결과가 내구성 있게 보관되지 않음 | 공간 정리·백업 가능한 결과 저장 |
| 잠김 | 제목·원문·키를 노출하지 않음 | 비밀값으로 해제 |

디자인 샘플에는 최소한 정상 흐름, 한 청크 실패, 저장 실패, 경계 대안, 할 일의 담당자·기한 미정, 잠금 화면을 포함하는 안이다. 접근성·키보드 탐색·명확한 분·초 표기·개인정보 안내를 확인한다. 샘플 데이터는 실제 회의 원문 대신 설명용 가상 데이터를 사용한다.
