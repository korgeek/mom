# 색상·입력 언어 목록 설정 — 검토안

**후속 결정으로 일부 대체됨:** 사용자는 준비된 목록에서 아이콘 추가를 승인하고 선택지 관리를 기존 `화면 · 언어` 탭 아래로 통합하도록 요청했다. 전체 앱 문구도 음성 메모/정리 노트로 맞춘다. 현재 화면·JSON 호환·검증 상태는 [최신 기록](../evidence/2026-10-17-memo-appearance/README.md)을 따른다. 아래는 최초 구현·배포 당시의 범위 기록이다.

상태: **2026-10-17 구현·변경 영향 검증·배포·운영 화면 확인 완료**. 실제 AI 검증이나 전체 제품 출시 검증 완료를 뜻하지 않는다. 최초 로컬 전용 승인 이후 사용자가 첨부 화면으로 적용 대상을 명확히 하고 커밋·배포를 직접 요청했다. 배포 제품 커밋은 `68f5531`이다.

## 목적과 확정 범위

2026-10-17 최신 사용자 결정은 설정에서 **색상과 사용 언어**를 관리하는 것이다. 사용 언어는 음성 준비 화면의 `사용 언어 · 복수 선택` 목록이다. 해당 화면 아래의 임의 언어 코드 입력을 설정 화면으로 옮긴다. 기존 테마·팔레트·화면 언어 선택은 유지한다. 아이콘은 기존 9개 기본 세트를 준비 화면에서 고르며 설정에 세트를 미리 보여준다. SVG 등록과 한국어·영어 문구 편집은 제외한다.

앞서 논의한 JSON 가져오기·내보내기·AI 수정 안내 프롬프트는 이 두 목록에 한정해 유지하는 설계안이다. 기본값을 제공하고 수정·복원한 목록을 브라우저 보관함에 암호화 저장한다. 사용자 지정 언어 목록은 제공사의 언어 지원을 보증하지 않는다.

## 화면과 동작

- 설정에 `음성 준비` 탭 하나를 추가한다. 회사 색은 준비 화면의 색상 선택지와 메모 제목 앞 아이콘에 적용한다. 기본 아이콘과 색상별 아이콘 미리보기를 제공한다. 기존 카드·행·버튼 스타일과 키보드 탭 이동을 따른다.
- 색상 행은 색상 선택기, `#RRGGBB` 입력, 미리보기, 저장·삭제를 제공한다. 별도 색상 키·이름은 만들지 않는다.
- 언어 행은 언어 코드와 표시 이름, 저장·삭제를 제공한다. 예: `ko / 한국어`, `fr / Français`.
- 각 목록에 추가와 `기본값 복원` 버튼을 둔다. 복원 범위는 해당 목록이고 저장된 음성 메모의 선택값을 다시 쓰지 않는다.
- 행 저장·삭제·복원은 검증 후 암호화 저장이 성공했을 때 화면의 적용 목록을 갱신한다. 저장 중 상태와 실패·재시도를 표시한다. 저장되지 않은 행 입력은 임시 상태임을 표시한다.
- 음성 준비 화면은 적용된 색상·언어 목록으로 선택지를 만든다. 언어 직접 입력 대신 `색상 · 언어 목록 관리 →`를 통해 새 설정 탭으로 이동한다. 메모마다 복수 선택하는 동작은 유지한다.
- 기존 메모의 현재 색상·선택 언어가 새 목록에 없어도 현재 선택으로 계속 표시하고 해제할 수 있게 한다. 저장된 색상 값, 언어 코드·순서, STT 결과·실행 기록은 목록 변경으로 수정하지 않는다.
- 새 메모의 현재 기본 색상 `#2B59C3`와 입력 언어 `ko`, `en`은 유지한다. 목록 편집은 선택지 관리이며 처리 기본값 변경을 포함하지 않는다.

## 기본값·저장·잠금

기본 목록은 현재 `ui/copy.ts`의 색상 6개와 언어 5개다. 보관함 Catalog에 선택적인 버전 1 목록 설정을 추가하고 기존 암호화·직렬화·트랜잭션·소유권 검사를 재사용한다. 색상·언어 각각 기본값과 다를 때 해당 배열을 보관한다. 필드가 없는 이전 보관함은 기본값을 사용한다. 저장된 필드가 손상된 경우 오류를 표시하고 조용히 기본값으로 덮어쓰지 않는다.

행 저장은 완료된 변경의 접수 경계다. 접수된 저장은 기존 잠금 장벽에서 완료를 기다리며 실패하면 기존 저장 실패 경로로 복구한다. 저장 전 임시 행 입력은 잠금 시 반영되지 않음을 표시한다. 잠금은 새 작업을 막고 목록·가져오기 미리보기·행 입력 등 복호화 데이터와 DOM 참조를 정리한다. 다른 탭의 소유권 변경이나 늦은 저장 응답이 잠금 화면에 목록을 다시 표시하지 않도록 기존 guard를 유지한다.

전용 서버·새 의존성·AI 호출을 추가하지 않는다. 이 목록은 잠금 해제 후 로컬에서 사용한다.

## 가져오기·내보내기·AI 수정 안내

내보내기는 기본값과 사용자 변경분을 합친 **현재 적용 목록**을 아래 형태의 UTF-8 JSON 파일로 저장한다. 아래 값은 형식 예시이며 실제 내보내기는 전체 적용 목록을 포함한다.

```json
{
  "format": "mom-color-language-settings",
  "version": 1,
  "colors": ["#3B82F6", "#03B26C"],
  "languages": [{ "code": "ko", "name": "한국어" }, { "code": "en", "name": "English" }]
}
```

`AI 수정 프롬프트 복사`는 이 JSON과 형식·검증 규칙, 요청 내용을 사용자가 덧붙일 안내를 평문으로 복사한다. 외부 AI 전송은 사용자가 선택한 도구에서 직접 수행한다. 안내는 색상·입력 언어만 수정하고 같은 형식의 JSON만 반환하도록 요청한다.

가져오기는 파일 읽기 → 전체 검증 → 색상·언어의 변경 전/후 미리보기 → 명시적 적용 → 단일 암호화 저장 순서다. 취소·검증 실패·저장 실패는 현재 적용 목록을 보존한다. 목록을 부분 적용하거나 파일을 코드로 실행하지 않는다. 파일·클립보드에는 이 두 목록과 형식 식별자·버전만 포함한다. 제공사 키·암호·메모·음성·전사·회의록·실행 기록은 포함하지 않는다. 내보내기와 복사는 보관함 밖의 평문이라는 안내를 둔다.

## 검증 규칙

- JSON 파일은 최대 256 KiB, 지정한 형식과 버전 1만 허용한다. 알 수 없는 필드, 누락된 목록, 잘못된 타입을 거부한다.
- 각 목록은 1~64개다. 색상은 `#RRGGBB`만 허용하고 대문자로 정규화하며 중복을 거부한다. CSS 표현식이나 URL은 받지 않는다.
- 언어 코드는 기존 입력과 같은 구문 범위(`^[a-zA-Z]{2,8}(?:-[a-zA-Z0-9]{1,8})*$`)를 사용하고 새 등록 값만 공백 제거·소문자 정규화한다. 코드 길이는 최대 64자, 표시 이름은 공백 제거 후 1~80 Unicode 문자이며 제어 문자를 거부한다. 코드 중복을 거부한다. 이름은 일반 텍스트로 표시한다.
- 이전 메모에 저장된 값은 정규화 과정에서 다시 쓰지 않는다. 목록 선택과 제공사에 전달하는 언어 힌트의 검증은 분리하고 기존 모델별 지원 검사를 유지한다.
