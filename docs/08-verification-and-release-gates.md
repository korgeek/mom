## V01 긴 합성 MP3의 브라우저 처리

2026-09-30 MacBook Air에서 기존 Chromium 151을 사용했다. 압축 프레임을 순차 처리했으며 전체 파일을 PCM으로 디코딩해 보관하지 않았다.

| 입력 | 청크 목표 | 겹침 | 출력 수 | 준비 시간 | JS heap 최대 |
| --- | --- | --- | --- | --- | --- |
| 1시간 합성 MP3 | 10분 | 10초 | 7 | 40.9초 | 61 MB |
| 2시간 합성 MP3 | 15분 | 15초 | 9 | 86.1초 | 97 MB |

총 16개 WebM/Opus 출력이 모두 완전 디코딩됐다. 최대 파일 크기는 4.32 MB, 길이 오차는 6~14 ms였고 브라우저 RSS 최대는 약 605 MB였다. heap과 RSS는 다른 지표다. 순차 처리 경로의 가능성을 보여주며 모든 메모리·브라우저 성능을 보장하지 않는다.

앞서 Chrome 154로 한 첫 시험은 약 1.1 GB에서 중지했다. 보수적으로 둔 900 MB guard가 작동했고 당시 시스템 여유는 약 60%였다. 기존의 더 가벼운 브라우저로 바꾸어 위 시험을 진행했다. 이를 시스템 메모리 부족이나 모든 Chrome의 필연적 실패로 해석하지 않는다.

**미검증:** 실제 긴 M4A/AAC, Ogg/Opus와 영상, 실제 말소리 압축 품질, 인증된 STT, 다국어 정확도, 겹침 텍스트 병합, 청크 간 화자 연속성, 저장 할당량·새로고침·보관·내보내기. 실험 파일이 Mac mini에 이전됐다고 가정하지 않았다.

## V02 OpenAI의 키 없는 전송 확인

같은 날짜 Air에서 키 없는 OPTIONS 200과 POST 401 오류 본문을 브라우저에서 읽었다. 해당 요청 조건에서 브라우저 전송 경로를 확인한 것이다. 실제 토큰·오디오 추론은 없었고 인증 성공, 전사 품질, 모델 가용성과 요금 결과는 확인하지 않았다. 이 기록에는 제공되지 않은 헤더·원점·본문 조건을 추가하지 않는다.

## V03 Cloudflare Workers AI의 preflight 실패

원점은 `http://127.0.0.1:61593`이었다. 더미와 사용자 실제 계정 경로를 대상으로 다음 세 suffix를 시험했다. 계정 식별값은 기록하지 않는다.

```text
/ai/run/@cf/openai/whisper-large-v3-turbo
/ai/run/@cf/meta/llama-3.1-8b-instruct
/ai/v1/chat/completions
```

OPTIONS는 405, 오류 7001과 OPTIONS 미지원 내용, CORS 헤더 없음으로 관찰됐다. 브라우저의 명시적 OPTIONS와 HTTP로 별도 모사한 POST preflight를 구분한다. 토큰·오디오·실제 POST 추론은 사용하지 않았다. 이 원점과 경로 조건에서 직접 호출안이 막혔다는 증거이며 모든 원점·향후 모든 정책에 대한 불가능성 증명은 아니다.

## V04 OpenRouter의 Mac mini 전송 확인

2026-09-30 14:41 UTC 무렵 `http://localhost:8769`에서 `https://openrouter.ai/api/v1/chat/completions`를 시험했다. Mac mini에 있던 로컬 보고서를 읽어 조건을 재확인했다. 보고서의 세션 정보·네트워크 추적 식별자·모델 목록 본문을 기획 문서에 복사하지 않았다.

| 시험 | 관찰값 | 해석 |
| --- | --- | --- |
| 별도 curl의 명시적 OPTIONS probe | 204, allow-origin `*`, POST와 Authorization·Content-Type 허용 | 해당 HTTP preflight 모사 조건의 응답 |
| 브라우저 명시적 fetch OPTIONS | 204, cors, 빈 본문 | 직접 OPTIONS 요청도 자체 preflight와 구분해야 함 |
| 브라우저 JSON POST | body `{}`, 빈 Authorization, Content-Type application/json, 401 JSON 읽힘 | 자동 POST preflight가 통과해 오류 응답을 읽음 |
| 공개 `/api/v1/models` GET | 200 | 공개 목록 전송만 확인 |

브라우저 401 본문에는 `No cookie auth credentials found`와 코드 401이 있었다. 자동 preflight의 정확한 응답 상태·전체 헤더는 직접 네트워크 캡처하지 않았으므로 curl 204와 동일한 관찰로 표기하지 않는다.

키·오디오·사용자 회의 자료·유료 호출·STT는 사용하지 않았다. 인증된 추론, 스트리밍, 모델 비교 품질과 음성 입력 지원은 미검증이다. 로컬 서버는 시험용 정적 화면·결과 저장용이며 MoM 제품 백엔드가 아니다.
