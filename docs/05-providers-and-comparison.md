# AI 제공자와 모델 비교

[문서 인덱스](README.md) · [검증 기록](08-verification-and-release-gates.md) · 기록 기준일 2026-09-30

초기 논의는 OpenAI와 Cloudflare Workers AI를 함께 쓰는 방향이었다. Cloudflare를 통한 공개 모델 시험도 목적에 포함했다. 이후 직접 브라우저 호출 제약을 확인하면서 **OpenAI STT와 OpenRouter 회의록 생성·모델 비교**를 조합하는 작업 설계를 제안했다. 제품화 논의는 이어졌지만 인증된 통합 성공이나 최종 제공자 확정으로 기록하지 않는다.

## 제공자별 상태

| 제공자 | 역할 후보 | 이번에 확인한 것 | 남은 것 |
| --- | --- | --- | --- |
| OpenAI | 청크 STT | 키 없는 OPTIONS 200과 POST 401 오류 본문을 Air 브라우저에서 읽음 | 실제 키·파일·모델의 인증된 추론과 다국어 품질 |
| OpenRouter | 텍스트 회의록과 모델 비교 | Mini에서 공개 모델 목록 GET 200, 빈 인증 JSON POST 401 본문, 별도 curl OPTIONS 204 | 선택 모델 추론, 긴 입력, 스트리밍·오류·비용·하위 제공자 |
| Cloudflare Workers AI | STT·공개 모델 비교 후보 | 특정 localhost 원점에서 세 경로 OPTIONS 405, 오류 7001, CORS 헤더 없음 | 다른 조건의 가능성과 별도 relay 승인 여부 |
| Cloudflare Workers Static Assets | 앱 코드·리소스 호스팅 | 로컬 Wrangler 설정과 공식 기능 | 실제 빌드·배포·운영 원점 테스트 |

Cloudflare Workers AI는 현재 직접 호출안에서 보류하는 것이 권장안이다. 추후 사용자가 자신의 relay를 별도로 승인하면 보안·키 관리·호스팅 책임과 데이터 경로를 다시 설계한다. 지금 프록시를 자동으로 추가하거나 인증·CORS를 우회하는 행동은 포함하지 않는다.

## CORS와 인증은 다른 검증

브라우저가 응답을 읽을 수 있으면 해당 조건의 전송 경로가 작동했다는 증거다. 401은 인증 실패이며 모델이 요청을 처리했다는 증거가 아니다. OPTIONS와 공개 모델 GET만으로 실제 파일 업로드, 모델 가용성, 유료 추론, 장시간 요청 또는 스트리밍을 보장할 수 없다.

OpenRouter Mini 시험에서는 JSON POST의 브라우저 자동 preflight가 통과했음을 읽을 수 있는 401 응답으로 확인했다. 자동 preflight의 정확한 상태와 전체 헤더는 직접 캡처하지 않았다. 별도 curl OPTIONS의 204와 허용 헤더는 별개 증거로 기록한다.

Cloudflare 시험은 `http://127.0.0.1:61593`과 당시 세 경로라는 조건에 한정한다. 명시적 브라우저 OPTIONS와 HTTP로 모사한 POST preflight를 구분한다. 실제 토큰·오디오·POST 추론은 사용하지 않았다. 모든 원점에서 영원히 불가능하다는 결론을 내리지 않는다.

## 제공자·모델 능력 표 제안

모델 선택 전에 파일 형식·바이트 제한, 전사 응답 형식, 언어 힌트, 단어·구간 시간, 화자 분리, 스트리밍, 입력 문맥과 출력 한도, 취소·결과 조회 능력을 확인한다. 지원하지 않는 옵션을 기본 UI로 켜 두지 않는다. 모델 목록에 이름이 있다고 해당 계정에서 요청 가능하다고 단정하지 않는다.

이번 문서에서는 최신 추천 모델명이나 가격을 고정하지 않는다. 공식 자료와 실제 실행으로 선택해야 한다. Cloudflare의 시험 경로에 등장한 `@cf/openai/whisper-large-v3-turbo`, `@cf/meta/llama-3.1-8b-instruct`는 **과거 시험 대상**이며 제품 선택 선언이 아니다. [Cloudflare REST 안내](https://developers.cloudflare.com/workers-ai/get-started/rest-api/)와 [해당 음성 모델 설명](https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/)을 참고한다.

## STT 비교

동일 원본 구간의 **동일 인코딩 파일**을 후보 모델에 보내는 안이다. 모델마다 변환이 필요하면 변환 차이를 기록하고 엄격하게 동일 조건인 비교와 구분한다. 입력 언어 힌트·용어 문맥·응답 옵션·실행 시각을 함께 남긴다.

전사 누락·추가, 고유명사·수치·부정 표현, 혼합 언어, 시간과 화자 능력, 경계 품질을 평가한다. 사람 정답이 없는 비교는 정답률이 아니라 상대적 관찰이다. 모델 A 결과를 모델 B의 정답으로 취급하지 않는다.

## 회의록 비교

고정한 전사 버전, 출력 언어, 섹션 순서, 추가 지시와 출력 길이 조건을 사용한다. 선택 모델과 반환된 실제 모델·하위 제공자가 다르면 기록한다. 동일 STT를 쓴 회의록 비교와 STT까지 다른 종단 결과 비교를 화면에서 구분한다.

결정 수정 반영, 할 일의 근거, 담당자·기한 창작 여부, 정보 누락, 출력 항목·언어 준수, 불확실성 처리와 읽기 쉬움을 평가한다. 실행 시간만으로 품질 우열을 결정하지 않는다. 여러 번 실행할 경우 결과 변동도 별도 관찰이다.

## 실행 경위와 비용

| 기록 | 이유 |
| --- | --- |
| 입력 파일·청크 또는 전사 버전 ID | 서로 다른 입력을 섞지 않기 위해 |
| 제공자·요청 모델·반환 모델·실제 하위 제공자 | 라우팅과 비교 조건을 확인하기 위해 |
| 인코딩·언어·생성 설정과 지시 버전 | 실행을 재현하기 위해 |
| 요청·완료 시각, 시도 번호, 결과 상태 | 지연과 재시도 경위를 파악하기 위해 |
| 제공된 사용량·청구 관련 값 또는 추정 근거 | 측정과 추정을 구분하기 위해 |

비용 표시는 `실측`, `추정`, `미제공`을 구분하는 안이다. 사전 비용은 확인한 요율과 예상 입력량으로만 계산하고 가격 출처·확인일·겹침·재시도·복수 모델 호출을 포함한다. 실제 청구값을 얻지 못하면 확정 비용으로 표시하지 않는다. 모델 목록 GET이나 키 없는 테스트에 실제 추론 비용 결과를 부여하지 않는다.

## OpenRouter의 데이터 경로

OpenRouter를 선택해도 추론을 수행하는 하위 제공자의 정책이 중요하다. 라우팅·폴백으로 실제 제공자가 바뀔 수 있는지 확인하고, 전송 대상과 정책을 사용자에게 설명해야 한다. 특정 데이터 보호 수준을 모든 모델에 일괄 적용한다고 약속하지 않는다. [제공자 목록](https://openrouter.ai/providers)을 기준으로 선택한 경로를 다시 확인한다.

[OAuth PKCE 안내](https://openrouter.ai/docs/guides/overview/auth/oauth)는 제공자 연결 방식의 참고 자료다. MoM에 OAuth나 계정 시스템을 넣기로 결정한 것은 아니다. 현재 방향은 사용자가 자신의 제공자 키를 입력하는 방식이며, 제공자 계정과 MoM 로그인은 구분한다.

## 오류와 재시도 제안

인증 오류는 키·권한 확인으로 안내하고 자동 반복하지 않는다. 요청 제한은 제공된 재시도 정보를 존중하고 제한된 재시도 정책을 검토한다. 크기 초과는 로컬 준비 단계로 돌아가게 한다. 네트워크 단절과 결과 불명은 중복 비용 가능성을 보여준다. 재시도는 선택 실패 청크 또는 선택 생성 실행에 한정하고 완료된 STT를 보존한다.

STT 병렬 요청 수, 자동 재시도 횟수와 모델 비교 동시성은 미결정이다. 초기에는 순차 또는 제한된 동시성으로 재현 가능한 실행을 먼저 검증하는 안을 권장한다.
