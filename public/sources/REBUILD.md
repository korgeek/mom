# Third-party codec source and replacement materials

[codecs/REBUILD.md](codecs/REBUILD.md) and [codecs/SOURCE_MANIFEST.json](codecs/SOURCE_MANIFEST.json) provide exact published encoder/decoder preferred-form source, MIT C/JavaScript wrappers, build/interface scripts, pinned library versions, unchanged binary hashes, full licenses and source-archive inventories. Runtime/font notices are at [/THIRD_PARTY_NOTICES.txt](/THIRD_PARTY_NOTICES.txt).

The prepared distribution contains independently licensed third-party codec source plus a dedicated object-relink utility and MP3 rebuild recipe. The two newly authored helper files remain MIT under [/licenses/MoM-CODEC-HELPERS-MIT.txt](/licenses/MoM-CODEC-HELPERS-MIT.txt). MoM-owned software is separately covered by the [MoM Source Available License 1.0](/licenses/MoM-SOURCE-AVAILABLE-LICENSE.txt), which preserves LGPL and existing recipient rights. This codec source package does not include MoM application preferred-form source, design-reference originals, internal/private documents, repository metadata, credentials or meeting data. A conservative full-app relink archive was prepared locally for review, then removed from the public input following the parent's explicit private-source boundary; it was never externally published.

LGPL2/2.1 section6 permits corresponding source and/or object material for the work using a library to enable modification/relinking; it does not automatically require publication of every application's preferred-form source. The shipped codec modules statically link their LGPL C libraries with supplied third-party C glue. The decoder can be replaced in the delivered compiled Worker object using `codecs/relink-decoder.mjs`, without MoM TypeScript or a source repository. It verifies exact hashes, one matching payload, WASM validity and supported import/export signatures before creating a separate output. The original host/wrapper behavior is retained; changed wrapper code or unsupported ABI changes require a separately verified procedure. `codecs/REBUILD.md` gives the recipient commands and limits. Source links alone are not a claim that every combined-distribution condition is satisfied.

A baseline byte-identical roundtrip and a valid metadata-only WASM replacement passed twelve guard tests and fresh headed Chrome WAV/MP3 preparation with independent output decoding. This proves this delivered-object replacement mechanism; it does not prove an Emscripten or behavior-changing source rebuild. The approved recipient own-use modification/debugging grant is [/licenses/MoM-OBJECT-PERMISSION.txt](/licenses/MoM-OBJECT-PERMISSION.txt) and remains unchanged under the MoM Source Available License. Application source remains excluded from this codec package; license adoption does not publish the repository. These materials accompany the authorized labelled test release; authenticated inference and complete-product quality remain unverified.

No Emscripten or compiler-produced, behavior-changing library rebuild was executed by this preparation. Exact npm/git artifact comparison is provenance evidence, not compiler-rebuild proof. The codec instructions preserve that limitation.
